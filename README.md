## Base de Datos: Gestión Académica y Contable

*Proyecto académico desarrollado en la asignatura Ingenieria de Datos I en la Universidad Argentina de la Empresa (UADE).*
**Estado:** Proyecto finalizado en noviembre 2025.

**Objetivo del Proyecto**
Diseño, estructuración y despliegue de una base de datos relacional orientada a administrar las operaciones académicas y contables de una institución. 
Este proyecto demuestra la capacidad para modelar estructuras de datos complejas, garantizando el rendimiento y la consistencia de la información.

**Tecnologías**
**_Motor de Base de Datos:_** SQL Server.

_**Entorno de Desarrollo:**_ SQL Server Management Studio (SSMS).

## Contenido del Repositorio
* Scripts DDL para la creación del esquema y las tablas relacionales (`CREATE TABLE`).
* Restricciones de integridad (Primary Keys, Foreign Keys, Check Constraints).
* Lógica transaccional básica para el manejo conjunto de datos académicos (alumnos, materias) y contables (pagos, facturación).

## Cómo utilizar este proyecto
1. Clonar el repositorio.
2. Abrir el entorno SSMS.
3. Ejecutar el script principal de creación de la base de datos para levantar la estructura en un entorno local.
